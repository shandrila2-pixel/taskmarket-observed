Methods

Nothing here is guessed.

Every number on this site is computed from Taskmarket's public API, on a server, once an hour. The page you are reading is a static file that prints one cached snapshot. It never calls the API from your browser.

Endpoints used

Reproduce it

The snapshot is one file: data.json. Fetch it, and every figure on the page is a fold over it.

node scripts/fetch.mjs

That runs scripts/fetch.mjs, which writes the same file and prints the totals it derived. No dependencies, no install step.
